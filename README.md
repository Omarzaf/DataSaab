# DataSaab

DataSaab is an early-stage game project whose gameplay concept is still being
defined publicly.

## Status

**Early concept — no playable release yet.** This repository is an honest
incubator, not a downloadable game, demo, or supported software release.

## Audience And Platform

The intended audience and delivery platform have not been selected yet. Those
decisions belong in the first architecture issue before implementation begins.

## Current Contents

- This project overview
- The MIT License for future original software in this repository
- No source code, assets, dependency manifest, build, tests, or release

## Roadmap

1. Define the player, core interaction, target platform, accessibility baseline,
   and success criteria.
2. Record the architecture decision and build one small playable vertical slice.
3. Test that slice against explicit release criteria and document a reproducible
   setup and verification path.

## Setup And Verification

There is currently nothing to install, build, or run. Setup and test commands
will be documented alongside the first executable code; CI should not imply
readiness before then.

## Contributions And Support

The project is not yet accepting code contributions. Use the issue tracker for
questions about the concept or its public roadmap. Repository-specific guidance
will replace the account defaults when implementation begins; no response-time
guarantee is implied.
